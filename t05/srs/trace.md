# Альтернативный разбор рекурсии (Задание 5)

## 1. Базовый случай и шаг рекурсии

* **Условие выхода (базовый случай):**
  `if (n <= 1) return 1;`
  Останавливает погружение в рекурсию, когда параметр достигает единицы или уходит в область неположительных чисел, возвращая фиксированный результат `1`.

* **Рекурсивный переход (шаг):**
  `return n * F(n - 1);`
  Уменьшает аргумент на единицу при каждом следующем шаге и умножает текущее `n` на результат вычисления функции от `n - 1`.

---

## 2. Трассировка вызова F(4)

Порядок выполнения: последовательный спуск по стеку вызовов вниз, затем последовательный расчет и подъем значений наверх.

| Шаг / Вызов | Глубина стека | Возвращаемое значение | Описание этапа |
| :--- | :---: | :---: | :--- |
| **Вызов `F(4)`** | 1 | **24** | Ожидает завершения `F(3)`, чтобы умножить `4 * 6` |
| **Вызов `F(3)`** | 2 | **6** | Ожидает завершения `F(2)`, чтобы умножить `3 * 2` |
| **Вызов `F(2)`** | 3 | **2** | Ожидает завершения `F(1)`, чтобы умножить `2 * 1` |
| **Вызов `F(1)`** | 4 | **1** | Достигнут базовый случай (`1 <= 1`), возвращает `1` |

## 3. Анализ вызова F(-1) при изменении условия на `n == 1`

Если модифицировать проверку на `if (n == 1)`, код примет вид:
```java
static int F(int n) { 
    if (n == 1) return 1; 
    return n * F(n - 1); 
}
