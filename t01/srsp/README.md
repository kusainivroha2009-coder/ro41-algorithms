# Практическая работа: Перевод секунд в часы, минуты и секунды

## 1. Словесная запись алгоритма
1. Начало работы программы.
2. Запросить у пользователя ввод целого числа секунд ($n$).
3. Считать введенное значение. Проверить его на корректность (является ли числом и выполнено ли условие $n \ge 0$).
4. Если ввод некорректный (буквы, пустая строка или отрицательное число), вывести сообщение об ошибке и завершить работу.
5. Вычислить количество часов: разделить $n$ на 3600 целочисленно ($hours = n / 3600$).
6. Найти остаток от деления общего количества секунд на 3600 ($rem = n \% 3600$).
7. Вычислить количество минут: разделить остаток на 60 целочисленно ($minutes = rem / 60$).
8. Вычислить оставшиеся секунды: найти остаток от деления полученного остатка на 60 ($seconds = rem \% 60$).
9. Вывести результат в формате `часы:минуты:секунды`.
10. Конец работы.

## 2. Псевдокод
```text
алг Перевод секунд
ввод input
если не целое(input) или input < 0 то
    вывод "Ошибка ввода"
иначе
    n := целое(input)
    hours := n div 3600
    rem := n mod 3600
    minutes := rem div 60
    seconds := rem mod 60
    вывод hours, ":", minutes, ":", seconds
все
