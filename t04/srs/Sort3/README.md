# Задание t04/srs — Сортировка трех чисел (Sort3)

## Описание проекта
Консольное приложение на C#, содержащее статический класс `Order` с двумя методами:
* `Swap(ref int x, ref int y)` — обмен значениями двух переменных.
* `Sort3(ref int a, ref int b, ref int c)` — упорядочивание трех чисел по возрастанию с использованием только метода `Swap` (без массивов).

## Результаты работы
Программа проверяет следующие наборы данных:
- `3 1 2 -> 1 2 3`
- `1 2 3 -> 1 2 3`
- `3 2 1 -> 1 2 3`
- `2 2 1 -> 1 2 2`
- `5 5 5 -> 5 5 5`
