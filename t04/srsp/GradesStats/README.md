# Задание t04/srsp — Статистика оценок (с методами)

## Описание проекта
Консольное приложение на C#, разделенное на статический класс `Grades` и основной метод `Main`. Программа считывает оценки учеников, проверяет их на корректность с помощью констант и выводит итоговую статистику (количество оценок, сумму, количество пятерок и средний балл).

---

## Таблица тестов

| № | Входные данные (построчно) | Ожидаемый результат / Поведение |
| :-: | :--- | :--- |
| **1** | `5`, `4`, `5`, `0` | Всего оценок: 3, Сумма: 14, Пятерок: 2, Средний балл: 4.67 |
| **2** | `0` | Сообщение: «Оценок нет» |
| **3** | `3`, `7`, `abc`, `2`, `0` | Вывод ошибок для `7` и `abc`, успешная обработка `3` и `2`. Итог: Всего оценок: 2, Сумма: 5, Средний балл: 2.50 |

---

## Структура проекта
* `Program.cs` — точка входа и основной цикл программы.
* `Grades` (статический класс) — методы `Read()`, `IsValid(int g)` и `PrintStats(...)`.
